{{define "admin-whitelist"}}

Enforce on effectively flips the relay from public to private: only listed users can write events. Use this for community relays, app-specific relays, or any deployment that should reject strangers at the door.

Enforce off leaves the relay public, but the whitelist is still grain's "elevated users" registry — listed pubkeys/npubs/domain members get privileged treatment in other features (e.g. purge protection). So a list with Enforce off isn't useless; it's just not the access gate.

Kind whitelist

Common patterns:

  • Indexing relay: allow only 0 (metadata), 3 (follow list), 10002 (relay list metadata) — clients use this to discover identities and routing.
  • App-specific relay: allow only the kind(s) your app uses. Useful for custom kinds in the 40000+ range.
  • General-purpose relay: leave Enforce off so any kind is accepted; the whitelist still contributes to other features.
